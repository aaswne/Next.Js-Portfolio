# Portfolio Website

This is my personal portfolio website built using Next.js. It showcases my projects, skills, and experience as a frontend developer.

## 🚀 Features

- Modern UI built with Next.js (App Router)
- Responsive design for all devices
- Dynamic project pages
- Clean and reusable components

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- CSS / Tailwind (if you used it, tell me — I can adjust)

## 📂 Project Structure

- `app/` – Main application routes and pages
- `components/` – Reusable UI components
- `data/` – Static data (projects, etc.)
- `public/` – Assets like images and icons

npm run dev
